# Synthetic procedure-copy engineering demonstrations

These agent-authored engineering examples describe fictional staging systems.
They are upload inputs for connected workflow acceptance, not operational advice,
customer documents, development evaluation cases, blind cases, or model-quality
labels. No infrastructure commands are executed by these files.

Two source families are exposed: **Cedar cache restart** (an ordered numbered
procedure) and **Juniper release rehearsal** (four explicitly counted instruction
paragraphs, with an end marker and separate record-governance declaration).
Exclude both families, including renamed or paraphrased derivatives, from future
blind authoring. This exclusion applies to the replacement version as well.
Existing frozen corpora, labels and first-run reports remain separate.

| Upload file | Use |
| --- | --- |
| `cedar-cache-restart.txt` | Initial numbered source |
| `juniper-release-rehearsal.txt` | Initial declared-paragraph source |
| `juniper-release-rehearsal-v2.txt` | Replacement bytes for the same Juniper document, not a third source family |

`manifest.json` records exact upload-byte SHA-256 values, canonical body hashes,
instruction intervals, demonstration questions and source-family exclusions.
`SHA256SUMS` covers the public assets other than itself. All upload files are UTF-8
with LF endings; a final newline is removed by the existing connected canonical
content profile. Upload the TXT files only. Do not ingest this README or manifest.

Use a disposable local application explicitly configured for
`source_declared_procedure_copy_v1`, `qa_plus_source_patterns_v1`, reader selection,
local NLI support and extractive generation. The connected browser suite reads
`GROUNDTRUTH_SEED_MANIFEST` using the existing private seed-manifest convention;
no keys belong in these public assets. The suite selects each newly created
document ID exactly, checks actual normal/SSE responses, distinguishes
NLI-supported subject/applicability from exact structure/copy, opens immutable
sources, reloads saved queries, refuses an unsupported qualifier, and replaces
the Juniper source through the version UI before inspecting both snapshots.

Procedure discovery alone verifies grammar and literal ranges. It does not prove
local NLI acceptance, answer quality, API behavior or browser behavior. Live
execution remains **NOT RUN** until the integrator observes the scheduled suite.
No passing model result is encoded in this package.
